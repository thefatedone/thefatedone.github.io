## 🚀 About This Project

This is the source code for my personal portfolio website. It serves as a living
resume, a showcase of my best work, and a recruiter-friendly landing page — all
wrapped in a clean, dark-mode-first aesthetic with a signature mint accent.

The site is fully **static**, **dependency-light** (only Google Fonts + FontAwesome
via CDN), and **deployed automatically** through GitHub Pages on every push to `main`.

<br>
